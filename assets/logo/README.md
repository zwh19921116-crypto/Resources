# Logo

Drop your logo file here and name it **`logo.png`**.

- Path used by the site: `assets/logo/logo.png`
- Recommended: transparent PNG or SVG, roughly 400 × 110 px (displayed at 44 px tall)
- Using an SVG instead? Rename it `logo.svg` and update the `src` in [index.html](../../index.html) on the `.brand-logo` image.

If no file is present, the site falls back to the text wordmark automatically.
