# Thumbnail images

Drop card thumbnail pictures in this folder, then type the path into the
**Custom thumbnail image** field in `admin.html`, for example:

```
assets/thumbs/trigonometry.jpg
```

- Best size: **600 × 360px** (cards crop to 5:3)
- JPG or PNG, ideally under 150KB so cards load fast
- Leave the field blank to use one of the built-in illustrations instead

Note: Google Drive and Dropbox links do **not** work as image sources — put the
file here instead.
